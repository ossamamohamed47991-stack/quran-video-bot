# بوت الفيديوهات القرآنية 🌙

بوت تليجرام يولّد فيديوهات قرآنية (تلاوة + نص عثماني + خلفية) جاهزة للشورتس والريلز.

## التشغيل

1. **اعمل بوت** من @BotFather في تليجرام: `/newbot` → خد التوكن
2. حط التوكن في `config.py` (سطر `BOT_TOKEN`)
3. شغّل:
   ```
   .venv\Scripts\python.exe main.py
   ```

## الاستخدام في تليجرام

| الأمر | الوصف |
|---|---|
| `/start` | التعليمات وقائمة القراء |
| `2:255` | فيديو لآية الكرسي (القارئ الافتراضي: العفاسي) |
| `2:255-258` | **نطاق آيات** في فيديو واحد متواصل (أقصى 10 آيات) |
| `/video 2:255 husary` | بقارئ محدد |
| `/video 2:255 alafasy en` | مع ترجمة إنجليزية |

## القراء المتاحون (12)

`alafasy` (العفاسي) · `abdulbasit` (عبد الباسط مرتل) · `abdulbasit_mj` (عبد الباسط مجود) · `husary` (الحصري) · `minshawi` (المنشاوي مجود) · `sudais` (السديس) · `shuraym` (الشريم) · `gamdi` (الغامدي) · `maher` (المعيقلي) · `hudhaify` (الحذيفي) · `shatri` (الشاطري) · `banna` (البنا)

## المميزات

- **قص الصمت** من بداية ونهاية التلاوة (فلتر أمان — ملفات everyayah مقصوصة أصلًا)
- **حجم خط ديناميكي** حسب طول الآية (من 46 إلى 84 بكسل)
- **زوم خفيف (Ken Burns)** على الخلفية عشان الفيديو حي مش جامد
- **تحقق من أرقام الآيات** (جدول عدد آيات السور الـ 114)
- **نطاق آيات** بدمج مقاطع متواصلة
- التلاوة من `everyayah.com` (مباشرة) والنص من `api.alquran.cloud`

## ملاحظات

- الفيديو 1080×1920 (9:16) — مناسب لشورتس يوتيوب، ريلز، تيك توك
- البوت شغال محلياً على جهازك — لازم الجهاز يفضل شغال عشان البوت يرد
- عشان يشتغل 24/7، انقله لسيرفر (VPS) بعدين
- لو عايز تقيّد الاستخدام لنفسك: حط رقم ID بتاعك في `ALLOWED_USERS` في `config.py`
